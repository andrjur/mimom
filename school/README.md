# Сайт Андрея Индыкова для родителей

Статический сайт для GitHub Pages. Сборка не требуется.

## Что внутри

- `index.html` — основной лендинг;
- `diagnostics.html` — интерактивная диагностика подготовки без отправки данных;
- `prompts.html` — 10 учебных промптов с копированием и печатью в PDF;
- `assets/` — стили, скрипт и изображения;
- `.nojekyll` — корректная публикация на GitHub Pages.

## Публикация через интерфейс GitHub

1. Создайте новый публичный репозиторий, например `andrey-school`.
2. Загрузите в корень репозитория все файлы из этой папки.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем **Save**.
6. GitHub покажет адрес вида `https://USERNAME.github.io/andrey-school/`.

## Перед запуском продаж

1. Подтвердите цены и регламент ответов в чатах.
2. Создайте платные подписки в Tribute и замените ссылки «В лист ожидания» и «Узнать о старте» на платёжные.
3. После первых 100 посетителей подключите Яндекс Метрику и события на кнопках.
4. Когда станет известен итоговый домен, замените относительный `og:image` на абсолютный URL.

## Быстрая проверка локально

Откройте `index.html` двойным щелчком. Для полной проверки ссылок удобнее запустить локальный HTTP-сервер из этой папки.
