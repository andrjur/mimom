# Отзывы о практике «Один слой»

## Текущая доставка

Это статический сайт. Форма готовит сообщение в браузере и открывает личный чат https://t.me/Andreyjurievich с черновиком. Посетитель сам нажимает «Отправить» в Telegram. Без этого действия Андрей не получит отзыв. Сайт не знает, было ли сообщение отправлено.

Форма не отправляет данные на сервер, не содержит токенов, не сохраняет их в localStorage и не пересылает личные заметки упражнения. Публикация по умолчанию запрещена. Согласие на публикацию указывается отдельной необязательной галочкой и включается в сообщение. Если Telegram не подставил текст, доступны копирование и ручная вставка.

## Решение Андрея

1. Прочитать сообщение в личном Telegram.
2. Проверить отдельное разрешение на публикацию. Без разрешения ничего не публиковать.
3. Удалить из предполагаемого публичного текста контакты, диагнозы, чужие имена и лишние личные подробности. Если нужна содержательная правка, согласовать итоговую цитату с автором в переписке. Не переписывать негативный отзыв в положительный.
4. По решению Андрея добавить только согласованную цитату в `content/one-layer-reviews.json`. Файл публичный: не складывать сюда очередь, личные сообщения, Telegram ID и контакты.
5. Использовать поля `id`, `status` со значением `approved`, `publicationConsent` со значением `true`, `date` с реальной датой, `name` с разрешённой подписью или пустой строкой и `text` с согласованным текстом до 1200 символов. Шаблонные отзывы здесь не добавляются.
6. Пересобрать сайт и запустить проверки. Публиковать после прохождения проверки. Для удаления отзыва по просьбе автора удалить только соответствующую запись и пересобрать страницу.

Компонент показывает только записи со статусом `approved` и явным разрешением. Проверка сборки дополнительно запрещает неизвестные поля. Пока ни одного реального одобренного отзыва нет, список пустой.

## Автоматизация

Полностью автоматической отправки с сайта в этой версии нет. Для неё нужны отдельный серверный обработчик, проверенное подключение собственного Telegram-бота, личный числовой chat_id владельца, защита от спама и приватное хранилище очереди. Уведомление об успешной отправке нельзя показывать до подтверждения сервера. Бот Дианы и его подключения не используются.

Переход в личный чат и выбор публикации являются настоящим текущим маршрутом, а не имитацией серверной отправки. End-to-end доставку проверяет Андрей отдельным тестовым сообщением. До этой проверки нельзя объявлять, что отзыв фактически пришёл в Telegram.
