# Основной сайт indikov.ru

Главная и продуктовые страницы основаны на версии andrey-indykov из Sites. Школьное направление находится в `/repetitor/`, карточки в `/repetitor/cards/`, типировщик в `/sociotyper/`. Архив статей продолжает собираться Jekyll.

`npm ci`, затем `npm run build` из этой папки создают статический HTML в корне репозитория. Для существующей установки зависимостей можно задать `MARKETING_DEPS` с абсолютным путём к node_modules.

Форма обращения использует маленький отдельный скрипт `assets/marketing.js`. Она готовит текст для личного чата, не отправляет сообщения и не хранит ответы на сервере. UTM-метки сохраняются в переходах и добавляются в черновик.

Большие статические файлы загружаются через jsDelivr с закреплённым SHA публичного репозитория. При обновлении сначала публикуйте новые файлы, затем обновляйте `cdn.json` и пересобирайте HTML. Пользовательские ответы и запросы ИИ не отправляются этому CDN.
