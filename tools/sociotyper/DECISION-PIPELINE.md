# Как работает типирование evidence-2

Каждый участник анализируется отдельно. Текст и готовая расшифровка направляются в четыре запроса: базовые пять признаков, следующие пять признаков Рейнина, оставшиеся пять, квадра и восемь аспектов. В результате сохраняются все 24 поля протокола. Это группы проверок, их нельзя считать независимыми измерениями личности.

## Проверка наблюдений

В каждой группе извлекаются полюс, уверенность, короткая дословная цитата и ограничения. Инструкции внутри рассказа рассматриваются как данные. Предпочтение пользователя по ТИМу не направляется экстракторам. Все 16 типов сравниваются кодом.

В `cloudflare-worker/compact-pipeline.js` проверяются идентификаторы, допустимые полюса, числовые диапазоны и наличие цитаты в исходном материале. Цитаты из технических инструкций, замков и ответа модели не считаются исходным материалом. Повторяющиеся идентификаторы отклоняются. Отсутствующая проверка получает предупреждение.

## Расчёт

Клиент и сервер используют общий `cloudflare-worker/tim-definitions.js`. Содержание таблицы сохранено из прежнего приложения. Проверка вычислений не подтверждает эмпирическую точность таблицы или метода.

Веса: экстраверсия, логика, сенсорика и статика по 2; рациональность 0,5; десять дополнительных признаков по 0,25. Дополнительные признаки имеют ограниченный общий вес, поскольку связаны с базисом.

Вклад: `вес * max(0, (уверенность - 50) / 50)`. Без подтверждённой цитаты вклад нулевой. Минимальная длина цитаты 12 знаков. Если одна цитата подтверждает больше трёх шкал, её вклад уменьшается пропорционально повторному использованию.

Совпадение прибавляет вклад, противоположный полюс вычитает. Рейтинг сортируется по разности поддержки и возражений. Индекс поддержки равен поддержке, делённой на полную сумму весов. Пропуски остаются в знаменателе.

Один тип показывается при наличии трёх из четырёх базовых шкал, покрытии от 35 и отрыве от 8 баллов. Это начальные инженерные пороги для калибровки, не диагностическая точность. Высокая уверенность автоматически не присваивается.

Замки фильтруют кандидатов, но не создают доказательств. При противоречивом ограничении или недостатке материала результат открыт. Предпочтение по ТИМу и замки психософии не используются как доказательства соционического типа.

## Пояснение и продолжение

Пятый запрос получает проверенные наблюдения и рейтинг без полного рассказа. Он поясняет цитаты и ищет альтернативные объяснения. Его ответ не может изменить тип, баллы или пороги. Выдуманные цитаты отбрасываются. При сбое сохраняется рассчитанный результат.

Вопросы выбирает код по различающимся признакам двух верхних версий. Без материала задаются общие вопросы о конкретных решениях. «Дополнить рассказ» возвращает текст и вопросы в форму. Новый платный запрос самостоятельно не запускается.

При недостатке данных персональная Модель А и сравнение совместимости скрыты. Случайный выбор типа удалён на сервере и в локальном словаре. Через минуту доступны локальные наблюдения, пока сервер продолжает работу.

## API и ограничения

Dewiar получает POST на `https://dewiar.com/API/api` без добавления `/chat/completions`. Недокументированный `response_format` не отправляется. JSON проверяется после ответа. Реальный платный Dewiar-запрос пока не подтверждён.

Общий провайдер определяется `INCLUDED_PROVIDER`; готовность проверяется по ключу именно выбранного сервиса. Для Dewiar используются `DEWIAR_API_KEY`, `DEWIAR_MODEL`, необязательный `DEWIAR_REPORT_MODEL`. Ключи не публикуются в GitHub. BYOK подключается на странице без смены общего провайдера.

Аудио через новые агрегаторы не объявляется поддержанным. Нужна готовая расшифровка или отдельно настроенный аудиопровайдер.

Четыре извлечения и до одного пояснения. Расшифровка, проверка ключа, последующие вопросы и повторное типирование считаются отдельно. При лимите 10 запросов в минуту очередь добавляет около 18 секунд до старта четвёртой группы. Ускорение и экономия в рублях не измерены.

## Проверки

`npm test`: 16 строк таблицы, нейтральная уверенность, пропуски, выдуманные и повторные цитаты, замки, неизменность рейтинга, группировка запросов, частичный сбой и адреса API. `npx tsc --noEmit` и `npm run build`: клиент.

Локальный Workflow/D1 тест: 24 поля, отсутствие случайного типа, изоляция владельца, повторный ID без повторной оплаты, однократный возврат попытки при отмене. Это тесты реализации с подменным HTTP-провайдером, не проверка качества типирования реальных людей.
