## 🧠 Введение и концепция

**Соционический Типировщик (Socionics AI Typist)** — это высокотехнологичный инструмент, разработанный в соавторстве с лабораторией НейроИндыков, который объединяет классические подходы Карла Юнга, Аушры Аугустинавичюте, А. Афанасьева и современные генеративные нейросети. 

Система анализирует текст, аудио и контекстуальные паттерны пользователя, выделяя из них семантические маркеры, соответствующие функциям информационного метаболизма. В отличие от стандартных тестов (MBTI и пр.), которые опираются на саморефлексию и подвержены искажениям социальной желательности, наш проект анализирует **живую речь**, минимизируя эффект субъективной ошибки.

## 💡 Инновационные решения

### 1. Архитектура Umami Analytics Proxy
Одним из вызовов стала интеграция открытой аналитики **Umami**. Официальный Cloud API является платной функцией (Pro). Однако мы разработали элегантное решение для обхода этого ограничения на стороне нашего сервера (backend proxy).

**Как это работает:**
1. Вы создаете публичную ссылку (Share URL) на ваш дашборд в Umami Cloud.
2. Эта ссылка имеет уникальный `Share ID`.
3. Наш сервер (Express) принимает запрос от клиента, делает запрос к `https://cloud.umami.is/api/share/${shareId}`, чтобы получить динамический токен доступа (`x-umami-share-token`).
4. Затем сервер делает запрос от лица этого токена к закрытому API статистики (`/api/websites/{id}/stats`).
5. Данные форматируются и отправляются клиенту.

*Это позволяет получать всю полноту статистики (с графиками и картами кликов) прямо в приложении без покупки дорогостоящих API-ключей.*

### 2. Резервный Голосовой Ввод через Gladia API
Встроенный Web Speech API браузеров часто дает сбои. Для бесперебойной работы корпоративного типирования мы интегрировали поддержку **Gladia API**.
Gladia обеспечивает распознавание аудиофайлов с высочайшей точностью благодаря архитектуре Whisper Large-v3 и собственным моделям.
В настройках приложения пользователь может переключиться на Gladia и вставить свой ключ. Ключ нельзя записывать в исходный код или публиковать в GitHub.

## 🏢 Корпоративное использование (B2B)

**Socionics AI Typist** — это не просто развлекательный тест. Это мощный B2B инструмент для HR-специалистов, коучей и руководителей команд.

### Сценарии применения в Enterprise

1. **Рекрутинг и Онбординг:**
   - **Проблема:** Кандидаты часто приукрашивают свои навыки (Soft Skills).
   - **Решение:** Кандидат записывает 3-минутное аудио-эссе на отвлеченную тему ("Как я решил сложный конфликт"). Gladia API расшифровывает голос, LLM строит профиль ТИМа, и HR получает независимый срез: перед ним интроверт-логик или экстраверт-этик.

2. **Формирование команд (Team Building):**
   - **Проблема:** Конфликты в кросс-функциональных командах.
   - **Решение:** Модуль "Интертипные Отношения" и "Вектор Мотивации". Руководитель загружает профили сотрудников и получает Карту Совместимости. Система подсвечивает зоны риска (например, отношения "Конфликта" или "Ревизии").

3. **Снижение Выгорания (Burnout Prevention):**
   - **Проблема:** Сотрудники выгорают из-за задач, не соответствующих их природе.
   - **Решение:** ИИ выдает рекомендации по распределению задач на основе Психософии. "1-я Воля" получает автономию, "1-я Эмоция" — публичные задачи, "1-я Логика" — аналитику.

### Коммерческая ценность
- ⬇️ **Снижение текучести кадров:** Подбор правильных ролей с экономией до $15,000 на найме каждого нового сотрудника.
- ⏱️ **Экономия времени HR:** Автоматический скоринг за 10 секунд вместо 2 часов интервью.

## 🛠️ Архитектура и технические детали

### Стек Технологий
- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS v4.
- **Backend:** Node.js, Express, ESBuild (Единый CJS бандл).
- **LLM SDK:** `@google/genai` (Native Google Gemini SDK) и кастомные Fetch-запросы к Groq / DeepSeek.
- **Анимации:** Framer Motion (через `motion/react`).
- **Генерация документов:** `jspdf` + `html2canvas`.

### Структура проекта (Для контрибьюторов)
В целях оптимизации сборки и предотвращения Token Limits (для AI), проект разбит на модульные части:

| Директория | Описание назначения |
| --- | --- |
| `/src/components` | Изолированные React-компоненты (`ResultScreen.tsx`, `MonologueScreen.tsx`). |
| `/src/services` | Логика взаимодействия с API (`geminiService.ts`, `statsService.ts`). |
| `/src/data` | Статические данные, массивы знаний соционики (Модели А, описания Рейнина). |
| `/server.ts` | Express-сервер для проксирования запросов (Vite Middleware в Dev-режиме). |
| `/dist` | Скомпилированные бандлы фронтенда и `server.cjs` для продакшена. |

### Полный цикл сборки (Full-Stack ESM/CJS)
При запуске `npm run build` происходит сложный пайплайн:
1. `vite build` — компилирует клиентский React (SPA) в статику в `/dist/assets`.
2. `esbuild server.ts` — упаковывает backend в единый файл `/dist/server.cjs`, игнорируя ESM-импорты сторонних библиотек.
3. `npm start` — запускает сервер, который отдает статику на порту `3000`.

### Особенности интеграции AI (Gemini Structured Outputs)
Мы используем строгую валидацию JSON-схем в Google Gen AI. Вместо обычного текстового запроса, сервер передает жестко заданный `responseSchema`:
```typescript
const analysisSchema: Schema = {
  type: Type.OBJECT,
  properties: {
    tim: { type: Type.OBJECT, properties: { abbreviation: { type: Type.STRING }... } },
    dichotomies: { type: Type.ARRAY, items: { ... } }
  }
};
```
Это гарантирует, что ИИ не сломает фронтенд своим форматированием.

## 👥 Руководство для контрибьюторов

Мы рады любым пул-реквестам! Чтобы начать работу, следуйте этим шагам:

### 1. Клонирование и зависимости
```bash
git clone https://github.com/indikov/socionics-ai-typist.git
cd socionics-ai-typist
npm install
```

### 2. Настройка окружения
Создайте файл `.env.example` и `.env`:
```env
# .env
GEMINI_API_KEY=добавьте_как_секрет_на_сервере
UMAMI_API_KEY=добавьте_как_секрет_на_сервере
GLADIA_API_KEY=добавьте_как_секрет_на_сервере
```

### 3. Запуск сервера разработки
Для старта системы используйте:
```bash
npm run dev
```
*(Команда автоматически поднимет Express-сервер с подключенным Vite Middleware)*

### 4. Code Style & Rules
- **CSS:** Используйте только Tailwind CSS утилиты. Запрещено создание сторонних `.css` файлов.
- **Иконки:** Импортируйте строго из `lucide-react`.
- **Состояние:** Избегайте "Prop Drilling", используйте контекст, если вложенность превышает 3 уровня.
