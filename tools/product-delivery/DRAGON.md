# Дракон намерения

Страница получения: `/dragon/`. После активации открывается `/dragon-online/` и запускается скачивание того же набора, который продаётся на Lava. Скачать повторно можно по кнопке в онлайн-версии.

Отдельные страницы упражнений: `/dragon-online/techniques/<id>/`. Все 42 страницы и ресурсы reader закрыты серверной проверкой доступа, имеют `X-Robots-Tag: noindex, nofollow, noarchive`, `Cache-Control: private, no-store`. Страница выдачи содержит robots meta, пути исключены через robots.txt. Запрет индексации дополняет проверку доступа.

## Коды

`dragon_codes` содержит только SHA256 от 12 цифр, количество разрешённых получателей и использованные выдачи. Один анонимный аккаунт получает один доступ. Повторные запросы не расходуют выдачи. SQL-триггеры проверяют ёмкость и увеличивают счётчик атомарно. Существующие одноразовые коды двух других продуктов работают по прежним правилам.

Полные списки кодов находятся только в локальной папке владельца `output/dragon-site/codes.private.json`, отдельно от репозитория. Импорт: `dragon-import.private.sql`. Применять повторно безопасно: `INSERT OR IGNORE` не сбрасывает счётчики. Внутри также отдельные тестовые коды, не передавать их покупателям.

## Анонимные комментарии

Случайный токен в HttpOnly Secure SameSite=Lax cookie идентифицирует аккаунт этого браузера. Сервер хранит только хеш токена. Имя и email не запрашиваются. После очистки cookie или смены браузера это другой аккаунт: восстановить авторство прежних записей без дополнительного входа нельзя. Это ограничение прямо указано в интерфейсе.

Последние четыре корневых комментария видны сразу, старые загружаются под раскрывающимся блоком. По два последних ответа видны сразу, остальные скрыты. Пагинация использует дату и ID. Текст выводится через textContent, без выполнения HTML.

Для упражнений и общей онлайн-страницы один аккаунт может добавить одну новую запись или ответ за 600 секунд суммарно на всех страницах. Редактирование собственной записи не ограничено и не сбрасывает время создания. Серверный триггер обеспечивает паузу при одновременных запросах. На странице получения действует небольшая пауза от случайных повторов, 15 секунд. Скриншот добавлен первым авторским комментарием на странице получения.

## Закрытые файлы

`private-assets` исключена из Git и Jekyll. Исходный ZIP разбит на части до 20 MiB для ограничений Static Assets, при скачивании сервер последовательно соединяет их в один поток без изменения байтов архива. Части нельзя скачать по прямым адресам, в том числе через workers.dev. Схема и reader с упражнениями доступны только после выдачи. В веб-атласе использован SVG вместо PNG размером 28 MB.

Не включать в публичный Git файлы ZIP, HTML reader, исходные Markdown упражнений и списки кодов.

## Проверки

`node tools/product-delivery/test.mjs`: прежняя выдача двух продуктов.

`node tools/product-delivery/dragon-test.mjs`: конкурентные лимиты 1/5/10, повторы, защита ресурсов, происхождение запросов, недоступный архив, медленный режим, редактирование, пагинация.

`node tools/product-delivery/check-dragon.mjs`: локальная проверка приватной сборки, 42 страниц, ссылок на изображения, noindex и размера отдельных файлов.

`node tools/product-delivery/dragon-dev.mjs`: изолированная локальная версия на 127.0.0.1:3197. Её тестовый код существует только в памяти и не открывает доступ на сайте. Тестовые комментарии не передаются на production.
