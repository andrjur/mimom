# indikov.ru — единый GitHub Pages-сайт

В этом репозитории находятся:

- `/` — короткий персональный хаб Андрея Индыкова;
- `/repetitor/` — отдельная воронка для родителей и учеников;
- `/repetitor/diagnostics.html` — диагностика готовности;
- `/repetitor/student-test.html` — тест для ученика;
- `/repetitor/prompts.html` — учебные промпты;
- `/typolog/` — типологии, «9 сфер», менторинг и вход в психологический блог;
- `/articles/` — блог на Markdown, связанный с веткой типолога;
- `/pereSBorka.html` — отдельная программа Андрея и Юли;
- `/mila.html` — самостоятельная страница Милы;
- `/materials/` — пять PDF-шпаргалок;
- `/school/` и `/shcool/` — совместимые редиректы на `/repetitor/`.

## Публикация на GitHub Pages

Готовый пакет называется `mimom-redesign-v4.zip`. Это полная копия сайта после объединения с актуальным публичным репозиторием, поэтому в ней сохранён `/sociotyper/`.

1. Скачайте резервную копию репозитория или создайте ветку перед обновлением.
2. Загрузите **содержимое подготовленной папки в корень репозитория** (не саму внешнюю папку).
3. Откройте `Settings → Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`, ветку `main` и папку `/(root)`.
5. В поле `Custom domain` укажите `indikov.ru` и сохраните.
6. У регистратора домена задайте DNS-записи GitHub Pages. Точные актуальные значения берите из справки GitHub; после проверки включите `Enforce HTTPS`.

Файл `CNAME` уже включён. GitHub Pages автоматически соберёт Markdown-статьи через Jekyll.

Подробная инструкция именно для `mimom`: [DEPLOY_MIMOM.md](DEPLOY_MIMOM.md).

## Как добавить статью

Полная инструкция: [ADD_ARTICLE.md](ADD_ARTICLE.md).

Коротко: создайте файл `_posts/ГГГГ-ММ-ДД-название-latinicey.md`, вставьте заголовок и текст по шаблону, затем нажмите `Commit changes`. Через несколько минут статья появится в `/articles/`.

## Где менять ссылки и тексты

- главная страница: `index.html`;
- стили главной: `assets/site.css`;
- репетиторский раздел: `repetitor/index.html`;
- типологический раздел: `typolog/index.html` и `typolog/typolog.css`;
- контакты встречаются в HTML как `t.me/andreyjurievich` и `vk.ru/andrupsy`;
- PDF: `materials/`;
- нейрофотосессия: `assets/photos/`.
- логика интерактивных статей: `assets/article-tests.js`;
- ученический тест: `repetitor/student-test.html` и `repetitor/assets/student-test.js`.

## Важное перед публикацией

- не удаляйте `/sociotyper/`: он уже включён в полный пакет v4;
- если текущий сайт уже лежит в другом репозитории, сначала сохраните его копию;
- не публикуйте токены в файлах репозитория: для обычного GitHub Pages токен внутри сайта не нужен.
