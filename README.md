## Сборка маркетинговых страниц

Исходники перенесённой версии ChatGPT Site находятся в `tools/marketing-site/`. После изменения исходников:

```sh
cd tools/marketing-site
npm ci
npm run build
```

Сборка обновляет главную и продуктовые страницы, сохраняя школьный раздел, приложения и архив статей. `tools/` исключён из публикации Jekyll. Статьи находятся в `_posts/`; инструкция в `ADD_ARTICLE.md`.

Статические ресурсы загружаются с jsDelivr из закреплённого коммита этого же публичного репозитория. API приложений остаются на `indikov.ru`.

При изменении картинок, CSS или JavaScript сначала опубликуйте ресурсы в GitHub, затем укажите новый коммит в `tools/marketing-site/cdn.json` и пересоберите страницы. Для существующих ссылок на старый коммит нужно обновить соответствующие ссылки в HTML.

## Публикация

GitHub Pages публикует ветку `main` из корня репозитория. Файл `CNAME` содержит `indikov.ru`. После push проверяйте результат Pages в GitHub Actions и открывайте страницы на самом домене.

Готовые карточки работают без API-ключа. Для генерации и объяснений в карточках требуется подключённый ИИ. НейроТипировщик использует отдельный API; успешное открытие интерфейса не подтверждает успешность каждого запроса к модели.

Прежние страницы сохранены. `/neurocoaching/`, `/pereSBorka.html` и `/mila.html` доступны по прямым ссылкам. Старые `/school/` и `/shcool/` ведут в `/repetitor/`.
