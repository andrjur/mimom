Остался другом. Костя решил после проб оценить, есть ли смысл продолжать. Повторение само по себе не доказывает пользу.

Три пробы в своём темпе.

Другу можно сообщить только факт пробы и одно наблюдение, если вам обоим подходит такая договорённость. Денежный залог для этого не нужен.
