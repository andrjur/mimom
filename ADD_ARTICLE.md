# Как самостоятельно добавить статью

## Самый простой способ — через сайт GitHub

1. Откройте репозиторий сайта.
2. Перейдите в папку `_posts`.
3. Нажмите `Add file → Create new file`.
4. Назовите файл по шаблону:

   `2026-09-04-kak-gotovitsya-k-kontrolnoy.md`

   Дата — год, месяц и день. После даты — короткое название латиницей через дефисы.

5. Вставьте шаблон ниже и замените текст.

```markdown
---
layout: post
title: "Как подготовиться к контрольной без ночного марафона"
description: "Короткое описание для списка статей и поисковиков."
category: "Учёба"
---

Первый абзац: какую проблему решает статья.

## Первый подзаголовок

Обычный текст. Короткие абзацы читаются лучше.

- пункт списка;
- второй пункт;
- третий пункт.

## Вывод

Один конкретный следующий шаг для читателя.
```

6. Нажмите `Commit changes` два раза. GitHub сам пересоберёт сайт.
7. Через 1–5 минут откройте `https://indikov.ru/articles/`.

## Как добавить картинку

Загрузите файл в `assets/articles/`, например `kontrolnaya.jpg`. В статье вставьте:

```markdown
![Тетрадь с планом подготовки](/assets/articles/kontrolnaya.jpg)
```

Лучший размер обложки — 1600×900 пикселей, JPG или WebP до 500 КБ. Файл называйте латиницей без пробелов.

## Как исправить или снять статью

- Исправить: откройте `.md`-файл, нажмите значок карандаша, сохраните через `Commit changes`.
- Снять с публикации: удалите файл через меню GitHub. История останется в репозитории и материал можно восстановить.

## Где всё хранится

Отдельный хостинг и база данных для статей не нужны. Исходники лежат в GitHub, а GitHub Pages бесплатно собирает и отдаёт сайт. Домен `indikov.ru` только указывает на эту публикацию.
